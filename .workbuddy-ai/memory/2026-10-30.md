# 2026-10-30

## 新增「路径显示」规范并清理违规写法（跨到 10-30 凌晨）

- `AGENTS.md` 增加「路径显示」一节：界面上的路径必须是展开后的真实路径，不出现
  `%AppData%` / `%Temp%` / `%LOCALAPPDATA%`；宽度不够用 `TextTrimming` + ToolTip，
  不许把真实路径折叠成 `%APPDATA%`；变量形式只留给存储值与注释/文档示意。
- 新增 `Services/AppPaths.cs`：`RoamingRoot` / `LocalRoot` / `TempRoot` + `Expand()`，
  作为所有「要显示给用户的路径」的取值点。
- 修掉的违规点：
  - `DashboardPage.OpenDataDir_Click` 反馈条曾直接显示 `%AppData%\AstraBrew Launcher\data`；
  - `ConsolePage` 启动日志「工作目录 %AppData%\...」；
  - `TavernConfigPage.OpenConfigFile_Click` 反馈条里的 `%AppData%\...\config.yaml`；
  - `SettingsPage.ShowPath` 原先把真实路径折叠成 `%APPDATA%` 省宽度（现改为显示完整路径 +
    截断 + ToolTip），`Expand` 改为 `AppPaths.Expand`，安装步骤文案里的 `%APPDATA%\...\lib` 一并展开。
- 顺带把两处写死 `C:\Users\al01\AppData\Roaming\...` 改成按共享清单推导：
  `ExtensionsPage.TargetPath` / `ResourcesPage.DataRoot` 改为 `static readonly` +
  `Path.Combine(TavernInstances.Builtin.Path, ...)`，XAML 里的同名假路径默认值删除、改由构造函数填充；
  版本页「扫描」面板的示例路径改用真实的 `MyDocuments`。
- 保留（符合规则）：`LauncherSettings.DefaultExportPath/DefaultDataPath` 仍存 `%APPDATA%\...`，
  这是存储值，读出后必经 `Expand` 才显示；注释与 `AGENTS.md` 目录树里的变量写法属于文档示意。
- 遗留：`TavernInstances` 里 3 个**本地实例样例**仍是 `C:\Users\al01\...` / `D:\AstraBrew\...`
  （代表用户自己的外部目录，属演示数据，未改）。
- 验证：`dotnet build -p:Platform=x64` 0 警告 0 错误；`timeout 12` 启动返回 124、无 crash.log。
