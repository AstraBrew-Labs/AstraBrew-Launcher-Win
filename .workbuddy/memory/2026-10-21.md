## WinUI3 启动器项目初始化（AstraBrew Launcher，C# + WinUI 3）

- 技术栈：.NET 8 (`net8.0-windows10.0.19041.0`) + WinUI 3 (WindowsAppSDK 2.5.1)，MSIX 单项目打包模板，RootNamespace `AstraBrew_Launcher`。
- 布局架构：`MainWindow` = 48px 自定义标题栏（`ExtendsContentIntoTitleBar` + `SetTitleBar`，Mica Alt 背景）+ `NavigationView(Left, OpenPaneLength 216)` + 内容 `Frame`。
- 导航：`MainWindow.PageMap`（tag → Page）驱动，`NavigateTo(tag)` 统一入口 + `SyncSelection()` 保证侧栏选中同步；MenuItems 6 项 + FooterMenuItems（设置/关于）。默认路由 dashboard。
- 页面（`Views/`）：DashboardPage、TavernConfigPage、VersionPage、ExtensionsPage、ResourcesPage、ConsolePage、SettingsPage、AboutPage，均为静态占位内容，等待接真实服务层。
- 共享样式：`Styles/Controls.xaml`（App.xaml 合并）。关键 key：PageTitleTextStyle、PageSubtitleTextStyle、CardStyle、MetricCardStyle、CardTitleTextStyle、CardBodyTextStyle、CellTitleTextStyle、CellTextStyle、ColumnHeaderTextStyle、FieldLabelTextStyle、MonoTextStyle、PageRootStyle、SettingRowStyle。
- 窗口：代码里 AppWindow.Resize 1180x780（按 DPI 缩放）+ 居中；`App.MainWindow` 静态引用供页面跳转。

### 踩坑记录（重要）

- **FontFamily 不支持逗号列表**：`"Cascadia Mono, Consolas, monospace"` 在 WinUI3 会被整体忽略退回默认字体，必须写单一字体名，等宽统一用 `Consolas`。
- **ms-appx 图片在非打包（unpackaged）构建下解析不到**：输出目录没有 resources.pri，`ms-appx:///Assets/xxx.png` 破图。最终改为纯 XAML 绘制的渐变方块 + "A" 字标，零资源依赖。
- **非打包直接跑 exe 会 REGDB_E_CLASSNOTREG**：需 `-p:WindowsAppSDKSelfContained=true -p:WindowsPackageType=None` 才能双击运行；VS F5（部署 MSIX）不受影响。项目目前保持 MSIX 默认配置，未改。
- **ToggleSwitch 默认显示"开/关"**：设置类页面需 `OnContent="" OffContent=""` 才干净（对齐 Windows 设置页观感）。
- **表头与数据列对齐**：列定义末列用 `Auto` 会因按钮宽度不同导致星号列错位，表头与数据行必须都用固定宽度。
- 截图验证：Bash 后台 `&` 启动的 GUI 进程会随工具调用结束被回收，需 `run_in_background` 或同一次调用内 sleep+截屏；截图脚本 D:/tmp/shot_nocv.py（纯 ctypes + zlib，无 cv2 依赖）。
